The rule

A repository is not done because the code runs. It is done when a stranger can clone it, read the README, and see the thing working in under five minutes.

Every repo needs

  • · A README that says what it does and why it exists
  • · A licence, and a setup section that actually works
  • · A live link, or an honest “not deployed yet”
  • · A screenshot or a 30-second clip

What I avoid

  • · Tutorial clones with the tutorial’s name on them
  • · Five half-finished repos instead of one good one
  • · Committing to a framework I have not understood
  • · Writing the README last
