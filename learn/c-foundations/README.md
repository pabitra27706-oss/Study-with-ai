# C Foundations for Data Structures

This is the prerequisite topic for **Data Structures in C**. It builds the C skills the next topic assumes: input and types, control flow, functions, arrays, pointers, structs, and manual memory ownership.

## Work goes here

| File | What it is |
|---|---|
| `solutions/t1.c` … `t6.c` | Your own C programs, one per task |
| `answers.json` | Your own written answers to the rubric questions |
| `notes.json` | Three short reflections, written by the judge after review |
| `verdict.json` | The judge's verdict; do not pre-fill it |

The teaching pack lives in [`curriculum/topics/c-foundations.json`](../../curriculum/topics/c-foundations.json). Its six tasks total 100 points and each includes hidden cases. The worked examples are in [`curriculum/reference/c-foundations/`](../../curriculum/reference/c-foundations/)—attempt each task before reading its reference.

## Suggested order

1. Read the explanation and trace each small example yourself.
2. Watch only the recommended chapter ranges; the full video lengths are not the required watch time.
3. Write the six programs without copying a solution. Add a WHY comment for the pointer, bounds, loop, or allocation decision each task names.
4. Put your written answers in `answers.json` using the rubric IDs (`q1`–`q5`).
5. Ask for a review with **`check c-foundations`**.
6. After this foundation is secure, continue to **`data-structures-c`**.
