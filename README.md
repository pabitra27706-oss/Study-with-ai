**Target:** CST diploma student, WB APC Ray Polytechnic → CS career (skills, job, and opportunities).

Read `ROADMAP.md` first if you want the *what to do*; `LEARNING-JOURNEY.md` if you want the *why it works*.

## The two rules everything else depends on

1. **Attempt before you ask.** The AI asks you a question before it gives you an answer.
   *(Same model, opposite outcomes: Bastani et al., PNAS 2025 — unguarded AI left students 17% worse on an unaided exam.)*
2. **One closed-book, no-AI test every week.** It is the only metric that distinguishes learning from performing.
